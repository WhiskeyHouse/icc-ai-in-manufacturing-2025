# Guide Index

Use this map when you first open the repository. It groups the sprawling guidance into four buckets:

## 1. Quick Start & Environment
- `README.md` – Ignition development environment setup and Docker workflow
- `docs/DOCKER-SERVICES.md` – Compose service breakdown and ports
- `scripts/demo-preflight.sh` – Environment validation prior to running demos

## 2. Demos & Automation
- `demos/scripts/` – Shell entry points (`run-*.sh`, `demo-*.sh`)
- `demos/python/` – Python presenters (`demo-*-*.py`)
- `demos/go/` – Go-powered CLI flows (`demo-stack-*.go`, compiled binaries in `go/bin/`)
- `docs/demos/` – Written instructions, run orders, and auto-mode notes

## 3. Runbooks & Presentation Prep
- `docs/runbooks/` – Talk outlines, rehearsal checklists, presentation prep
- `docs/presentations/` – Slide outlines plus storage guidance for decks
- `presentations/` – Drop finalized slide decks (`.pptx`, `.key`, `.pdf`)

## 4. Product & AI Services
- `ARCHITECTURE.md` – High-level system overview
- `llama-index-service/` – Retrieval augmented generation microservice
- `rules-engine-service.py` – Ignition validation API
- `docs/AI-IGNITION-CONTEXT-ENGINEERING.md` – AI context engineering vision

> Tip: add this file to your onboarding welcome message so everyone starts with the same map.
