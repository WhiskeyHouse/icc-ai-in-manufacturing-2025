# Presentations

Store final presentation assets here (`.pptx`, `.key`, `.pdf`, exported images, videos).

## Guidelines
- Keep file names prefixed with the event or audience (e.g., `summit-2025-overview.pptx`).
- Include a short changelog in the deck notes or attach a markdown summary if multiple revisions are expected.
- Large binary files can bloat the repo — consider linking to shared storage if the deck exceeds ~50 MB.
- Reference supporting materials from `docs/presentations/` where outlines and talking points live.
